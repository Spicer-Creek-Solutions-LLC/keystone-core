# Release record — v0.5.0

This is the audit log of the v0.5.0 release ceremony, per
[`RELEASE-PLAYBOOK.md`](../../RELEASE-PLAYBOOK.md) §3. It is a
**skeleton committed before the ceremony** — the Release Manager fills
the timestamps and verification evidence during the cut and commits the
completed record post-publication (as was done for v0.1.0).

v0.5.0 is the first release on the v0.x line after v0.1.0. It ships
**unsigned**: per the §6 carve-out, the `v0.1`–`v0.7.x` line ships without
signed tags / checksums / SBOMs, with `sha256sum -c` + TLS-to-forge as the
integrity check. Release signing begins at v0.8.
