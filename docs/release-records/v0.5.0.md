# Release record — v0.5.0

The audit log of the v0.5.0 release ceremony, per
[`RELEASE-PLAYBOOK.md`](../../RELEASE-PLAYBOOK.md) §3. Filled in
post-publication on 2026-06-27.

v0.5.0 is the v0.5 external-tester milestone and the first release on the
v0.x line after v0.1.0. It ships **unsigned**: per the §6 carve-out, the
`v0.1`–`v0.7.x` line ships without signed tags / checksums / SBOMs, with
`sha256sum -c` + TLS-to-forge as the integrity check. Release signing
begins at v0.8.

**Deviations from the full ceremony (acceptable for an unsigned v0.x
cut, recorded for honesty):** the build and publish were performed from
the maintainer's working environment rather than a separate air-gapped
workstation; the dual-machine reproducibility cross-check (§4) was not
performed (single machine); the §10 post-publication verification was a
fresh download into a clean temp directory on the same machine rather than
a third machine.
