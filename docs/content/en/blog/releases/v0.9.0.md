We're excited to announce Keystone Core v0.9.0, a major release that completes the core feature set with a powerful plugin system, comprehensive multi-environment support, and production-ready observability.

## Highlights

- **Plugin System (Epic 9)**: Extensible module system with Starlark and WASM runtimes
- **Multi-Environment (Epic 8)**: Unified support for Kubernetes, VMs, bare metal, edge, and cloud
- **Observability (Epic 7)**: Complete metrics, logging, tracing, and TUI monitoring

## New Features

### Plugin System

The new plugin system enables secure, sandboxed extensibility:

**Runtimes:**
- **Starlark Runtime**: Sandboxed Python-like scripting for state modules
- **WASM Runtime**: High-performance WebAssembly execution via Wasmtime

**Capability System:**
- 10 capability types with fine-grained permissions
- Path/domain/command scoping for security
- Rate limiting and resource limits

**Module Management:**
- SemVer constraint-based dependency resolution
- Minimum Version Selection (MVS) algorithm
- Content-addressed caching
- Cryptographic verification (Cosign signatures, SumDB)

**SDKs:**
- Starlark SDK with testing framework
- Rust SDK for WASM modules
- Go SDK (TinyGo) for WASM modules
- C++ SDK for WASM modules

**Standard Library:**
- `std/files` - File operations
- `std/exec` - Command execution
- `std/http` - HTTP requests
- `std/strings` - String utilities
- `std/json` - JSON encoding/decoding
- `std/crypto` - Cryptographic functions

### Multi-Environment Support

Unified infrastructure management across all environment types:

**Kubernetes:**
- Client wrapper with multi-cluster support
- CRD definitions (RemoteExecution, StateConfig)
- Operator controllers with reconciliation loops
- Kubernetes state modules (k8s_namespace, k8s_deployment)

**Virtual Machines:**
- Automatic platform detection (Linux, Windows, macOS)
- Distribution detection (Ubuntu, CentOS, RHEL, Alpine, etc.)
- Package manager detection (apt, yum, dnf, pacman, etc.)
- Init system detection (systemd, upstart, sysv, etc.)

**Bare Metal:**
- Hardware detection (CPU, memory, disk, network)
- IPMI/BMC integration for out-of-band management
- Extended agent metadata with hardware information

**Edge:**
- Offline mode with local buffering
- Connection resilience with automatic reconnection
- Resource-constrained operation
- Local state caching with TTL

**Cloud Providers:**
- AWS (EC2, ECS, Lambda detection)
- GCP (Compute Engine, GKE, Cloud Functions)
- Azure (VMs, AKS, Azure Functions)
- Automatic cloud provider detection

**Container & Service Mesh:**
- Docker and containerd runtime detection
- Istio, Linkerd, Consul integration
- mTLS and SPIFFE ID extraction

### Observability

Production-ready monitoring and observability:

**Metrics:**
- Prometheus integration with 70+ metrics
- Specialized collectors (control plane, agent, state, GitOps, policy)
- HTTP `/metrics` endpoint

**Logging:**
- Structured logging with correlation IDs
- Multiple formatters (JSON, logfmt, text)
- Configurable log levels

**Tracing:**
- OpenTelemetry integration
- OTLP exporter support
- Distributed trace context propagation

**TUI Monitor (`kscore-monitor`):**
- Real-time terminal dashboard
- 8 interactive views (Dashboard, Agents, Events, State, Policy, Jobs, Logs, Metrics)
- Keyboard navigation and filtering

**Grafana Dashboards:**
- Keystone Core Overview
- Control Plane Health
- Agent Fleet
- State Management
- Policy Compliance
- GitOps Operations

**Health Checks:**
- Kubernetes-compatible liveness/readiness probes
- Detailed status endpoint
- Circuit breaker pattern

**Profiling:**
- pprof endpoints for performance analysis
- CPU, memory, goroutine profiling

## Upgrade Instructions

### From v0.8.x

1. **Backup your data:**
   ```bash
   cp -r /var/lib/kscore /var/lib/kscore.backup
   ```

2. **Stop services:**
   ```bash
   systemctl stop kscore-server kscore-agent
   ```

3. **Upgrade binaries:**
   ```bash
   # Download v0.9.0 release
   wget https://github.com/shawnbutts/keystone-core/releases/download/v0.9.0/kscore-v0.9.0-linux-amd64.tar.gz
   tar -xzf kscore-v0.9.0-linux-amd64.tar.gz
   sudo mv kscore-* /usr/local/bin/
   ```

4. **Start services:**
   ```bash
   systemctl start kscore-server kscore-agent
   ```

5. **Verify upgrade:**
   ```bash
   kscorectl version
   ```

### Configuration Changes

No configuration changes required for this upgrade.
