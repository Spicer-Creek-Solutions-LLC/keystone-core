## Prerequisites

Before starting these tutorials, ensure you have:

1. **Keystone Core installed** - See [Installation Guide](/docs/getting-started/installation/)
2. **At least one agent running** - See [Quick Start](/docs/getting-started/quick-start/)
3. **Basic YAML knowledge** - States are defined in YAML

## Tutorial Format

Each tutorial includes:

- **Overview**: What you'll build and learn
- **Prerequisites**: Specific requirements for the tutorial
- **Step-by-step instructions**: Detailed commands and explanations
- **Complete code**: Full working examples
- **Next steps**: Where to go from here
