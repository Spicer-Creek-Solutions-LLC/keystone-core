Keystone Core is the runtime operations control plane between deployment
tooling (GitOps/IaC) and day-2 operations. Use the sidebar to browse:

- **Reference** — project design, configuration, CLI, API, security, and
  governance documentation (the canonical `docs/project/` tree).
- **Operations** — day-2 runbooks for cluster lifecycle, recovery, and
  incident response.
- **Architecture Decisions** — the ADR log.
