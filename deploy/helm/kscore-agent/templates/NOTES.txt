================================================================================
                               VERIFY AGENTS
================================================================================

1. Check DaemonSet status:
   kubectl get daemonset {{ include "kscore-agent.fullname" . }} -n {{ .Release.Namespace }}

2. Check running agents:
   kubectl get pods -l app.kubernetes.io/name={{ include "kscore-agent.name" . }} -n {{ .Release.Namespace }}

3. View agent logs:
   kubectl logs -l app.kubernetes.io/name={{ include "kscore-agent.name" . }} -n {{ .Release.Namespace }} --tail=100

4. Check agent health (from control plane):
   # If you have kscorectl installed:
   kscorectl exec --target="*" -- echo "Agent is healthy"

================================================================================
                               TROUBLESHOOTING
================================================================================

If agents are not connecting:
1. Verify the control plane address is correct
2. Check network policies allow agent -> control plane communication
3. Verify TLS certificates if TLS is enabled
4. Check agent logs for connection errors

Common issues:
- DNS resolution: Ensure the server address is resolvable from agent pods
- Port accessibility: Ensure port {{ .Values.server.address | regexFind ":[0-9]+" | trimPrefix ":" | default "9090" }} is accessible
- NATS connectivity: Ensure NATS port (4222) is accessible if using direct connection
