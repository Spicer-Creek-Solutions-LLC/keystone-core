Keystone Core

GitOps deploys it. We keep it running.

Keystone Core is the runtime operations control plane between deployment tooling (GitOps/IaC) and day-2 operations.

Documentation site coming with v0.5. During v0.1.x (the current soft-launch line), documentation lives as rendered Markdown in the source repository. A full Hugo-based documentation site lands with the v0.5 external-tester milestone.
